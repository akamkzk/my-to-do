# 周报生成流程

## 信息收集

按以下顺序引导用户提供信息。如果用户已提供完整信息，跳过对应步骤。

### 第一步：基本信息
- 姓名
- 本周日期范围（自动计算 ISO 周数）

### 第二步：今日完成
- 当天已完成的具体任务（每项一句话描述）

### 第三步：本周开发详情
- **已完成**：按模块/功能分组列出
- **进行中**：模块名 + 进度百分比 + 下一步计划
- **问题与风险**：遇到的问题、影响、解决方案

### 第四步：下周待办
- 按优先级列出待办事项

### 第五步：备注（可选）
- 其他需要说明的事项

## 内容整理规则

1. **分组归类**：将零散任务按模块/功能归类
2. **精炼表述**：每条工作内容 1-3 句话，避免流水账
3. **进度估算**：对"进行中"任务给出合理的百分比
4. **问题结构化**：采用"问题 + 影响 + 方案"格式
5. **优先级排序**：待办事项按重要程度排列

## 生成与确认

1. 按 `references/report-template.md` 中的模板生成周报
2. 输出完整周报
3. 询问用户是否需要：
   - 调整措辞或篇幅
   - 增删任务项
   - 修改格式
   - 导出为文件

## 特殊场景

### 用户一次性提供完整信息
直接生成周报，无需逐项追问。

### 用户只提供部分内容
基于已有内容生成初稿，然后询问补充缺失的部分。

### 用户要求导出
将周报保存为 `.md` 文件到用户指定路径，默认保存到 `reports/` 目录（不存在则创建）。
