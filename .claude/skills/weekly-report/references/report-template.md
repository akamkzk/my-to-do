# 周报模板

## 标准格式

```markdown
# 周报

**日期范围：** YYYY-MM-DD ~ YYYY-MM-DD（第 WW 周）
**姓名：** [姓名]
**生成日期：** YYYY-MM-DD

---

## 一、今日完成

- [ ] [任务名称]：[完成情况简述，1-2 句话]
- [ ] [任务名称]：[完成情况简述]

## 二、本周开发详情

### 已完成

- **[模块/功能名]**
  - 具体工作内容
  - 技术要点或成果（可选）

- **[模块/功能名]**
  - 具体工作内容

### 进行中

- **[模块/功能名]**
  - 当前进度：XX%
  - 已完成的阶段
  - 下一步计划

### 问题与风险

- [问题描述]：[影响范围] + [解决方案/当前进展]（如无则省略此节）

## 三、下周待办事项

- [ ] [待办项]：[简要说明]
- [ ] [待办项]：[简要说明]

## 四、备注

- [其他需要说明的事项]（可选）
```

## 写作规范

### 语言风格
- 使用简洁、专业的中文
- 技术术语保留英文原文（API、React、TypeScript、Vite 等）
- 每条工作内容控制在 1-3 句话

### 日期格式
- 统一使用 `YYYY-MM-DD`
- 周数使用 ISO 周数，格式为"第 WW 周"

### 内容组织
- **已完成**：按模块/功能分组，先写核心功能再写辅助工作
- **进行中**：标注合理进度百分比，说明卡点
- **问题与风险**：采用"问题 + 影响 + 方案"三段式
- **待办事项**：按优先级排序，标注明确预期

### 示例

#### 示例：前端开发周报

```markdown
# 周报

**日期范围：** 2026-07-06 ~ 2026-07-10（第 28 周）
**姓名：** 张三
**生成日期：** 2026-07-10

---

## 一、今日完成

- [ ] 修复搜索框防抖延迟问题：将 debounce 时间从 500ms 调整为 300ms，提升搜索响应速度
- [ ] 更新统计面板样式：优化进度环 SVG 渲染，适配暗色主题

## 二、本周开发详情

### 已完成

- **标签页切换功能**
  - 完成全部/未完成/已完成/统计四个标签页的条件渲染
  - 实现各标签页实时计数显示
  - 添加切换动画效果

- **搜索与筛选模块**
  - 实现搜索框防抖逻辑（300ms）
  - 完成分类筛选下拉框和优先级筛选按钮
  - 搜索结果高亮匹配文本

### 进行中

- **数据持久化**
  - 当前进度：80%
  - 已完成：TodoStore 类编写、localStorage 读写逻辑
  - 下一步：添加数据迁移兼容逻辑、异常恢复机制

### 问题与风险

- localStorage 存储空间限制：单用户数据超过 5MB 时写入可能失败。当前方案：添加容量检测并在超出时弹出提示，后续考虑迁移到 IndexedDB。

## 三、下周待办事项

- [ ] 完成数据持久化的异常恢复逻辑
- [ ] 开始多语言支持（i18n）模块开发
- [ ] 编写主要功能的注释文档

## 四、备注

- 项目已确定技术栈：React 19 + TypeScript + Vite 7
- 计划下周五进行第一次代码审查
```
