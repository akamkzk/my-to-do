# 周报生成

根据用户提供的本周工作信息，生成一份结构清晰、语言专业的中文周报。

## 快速开始

1. 判断用户是否已提供完整信息：
   - 是 → 跳到步骤 2
   - 否 → 按 `references/workflow.md` 中的信息收集流程逐项引导

2. 整理内容并按 `references/report-template.md` 中的模板生成周报

3. 输出周报后询问是否需要调整

## 内容整理规则

- 将零散任务按模块/功能分组
- 每条工作内容控制在 1-3 句话
- 进行中任务标注合理进度百分比
- 问题描述采用"问题 + 影响 + 方案"三段式
- 待办事项按优先级排序

## 写作规范

- 全程使用中文（简体）
- 日期格式统一为 `YYYY-MM-DD`
- 周数使用 ISO 周数（第 WW 周）
- 技术术语保留英文原文（API、React、TypeScript 等）
- 避免流水账，突出成果和技术要点

## 导出

如需保存文件，保存到 `reports/` 目录（不存在则创建），文件名格式：`周报-YYYY-MM-DD_姓名.md`。
